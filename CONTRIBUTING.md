# Contributing

latitude-fingerprint is a small solo project and is not accepting code or
documentation pull requests at the moment. That keeps it easy to review and
maintain. If that changes, this file will say so.

## What is welcome

- **Bug reports.** Open an issue with a clear reproduction, your Ubuntu version,
  and your laptop model.
- **Security issues.** Please report privately, not in a public issue. See
  [SECURITY.md](SECURITY.md).
- **Ideas and questions.** Open an issue describing what you are trying to do.
