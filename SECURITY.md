# fingerprint-driver — Security

What fingerprint-driver protects against, what it doesn't, and how to use
it sensibly.

---

## Supported versions

Security fixes are issued for the current minor release. Older releases
receive critical-only fixes when feasible.

| Version | Supported |
|---------|-----------|
| 0.x | ✅ active |
| < 0.0 | ❌ unmaintained |

If you cannot upgrade and have a security concern, raise it via
`daniel@themalwarefiles.com` — we will assess case-by-case whether a backport is
practical.

## Reporting security issues

If you discover a security vulnerability in fingerprint-driver, please
report it privately rather than opening a public issue. Use the
repository's security advisory system or email daniel@themalwarefiles.com.

Please do not disclose vulnerabilities publicly until they have been
assessed and a fix is available.
